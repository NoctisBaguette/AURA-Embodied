  lingbot/full-evaluation — teammate B's work.

For a new local checkout, if Git is already available:
  git clone --branch lingbot/competition https://github.com/NoctisBaguette/AURA-Embodied.git
  cd AURA-Embodied
Then choose ONE role branch:
  A: git switch --track origin/lingbot/portable-package
  B: git switch --track origin/lingbot/full-evaluation

Existing checkout: do not overwrite uncommitted work; use a separate checkout or preserve your changes first. No GPU/environment setup is needed merely to read and edit CPU tools. Repository write permission is not automatically granted by this handoff. Without permission, return changed files/patches to the captain or use your own fork and PR. No access invitation has been sent on your behalf.

Your AI may read the branch URLs or the attached LingBot-AURA-Workspace-20261021.zip. Start with the role-specific prompt inside lingbot/. If it cannot browse the branch or inspect ZIPs, attach the source files listed in the read-first document. Do not assume it can SSH into the server or access the private archive.

Daily reports: reports/YYYY-MM-DD/A.md or B.md, on the owner's branch, or send the report privately. Follow 06-DAILY-REPORT-EN-ZH.txt through 23 October. Include actual file/commit identities, checks versus NOT RUN, remaining work and takeover steps. Remove host details/private logs from public reports. Reports are not scheduled or sent automatically.

The current server workflow continues independently. GitHub changes do not deploy, restart or monitor it. The latest supplied snapshot is BASELINE 8/32, commission 16/16. Dates and evidence attribution matter; do not treat this as a live dashboard.

AURA-Embodied is public. Reference copies replace host-specific paths with /path/to/...; they are for inspection and adaptation, not direct server execution. New A/B implementation work is integrated here, so there are not two competing development copies. The earlier teammate ZIP remains useful background, but follow this branch/path routing going forward.
