**Inputs:** [DynaHarness](https://github.com/search?q=DynaHarness&type=repositories) as *historical lead requiring identity/primary audit before numerical claims*, RoboArchitect ([2610.42141](https://arxiv.org/abs/2610.42141)), AMP1 ([2611.09892](https://arxiv.org/abs/2611.09892); [official code](https://github.com/apple-aiml-research/ml-amp)), RoboACE ([2611.13034](https://arxiv.org/abs/2611.13034)), [kNN](https://arxiv.org/abs/2611.13160), [phantom progress](https://arxiv.org/abs/2611.14488), and AURA's actual M8/M9a boundary.

**Deliverable:** append **one dated versioned addendum** to the existing WP1 comparison matrix, not a new architecture design. Per method: real/privileged inputs, policy frozen/changed, task-level effect verification, memory indexing, control latency, model/tool costs, target-shift types, artifact status, and comparisons' denominators. Provide one falsifiable AURA question and one clear case in which the simplest alternative may win.

**Acceptance:** sources pinned; distinguish reported outcomes from local evidence; explicit wall-time/cost caveat for AMP1 (simulation can pause); no assumption that a 404 advertised kNN repository is reproducible; DynaHarness factual claims only when primary record is checked. **Excluded:** modifying architecture/DEC, approving new studies, deploying agent software.
