## 给 HQ、BAGUETTE Core/02 和 06 的核心结论

**不改变 M9a 已授权的传感与验证调试范围。**本周真正值得更新的是**竞争性先前工作（prior art）与实验归因（attribution）**。RoboDoctor、RoboAuto 在策略/智能体切换、物体知识、主动探测、诊断、局部修复及经验复用上与 AURA 的长期设想显著重叠；PDRVLA 则提供另一种可能更简洁的方案：在**训练时**学习物理预测知识，在线执行时不再运行完整视频世界模型。这要求 02 审视创新性和必要性，但**不构成改写正在进行的 M9a 的理由**。

**本周新增实验候选为零。**此前已有的下一检查点建议仍是：非特权感知基线得到接受后，比较**证据时效性/任务状态失效处理**；**按干预价值选择继续/重观测/局部恢复**是备选方向。必须先把现有 M9a 的 Vulkan/相机、录像、严格物理不扰动性、Core 协议验收做完。

## 二、独立发现及技术解读（以下分数均为作者报告，不是 AURA 实验）

### A. RoboDoctor：不更新权重的执行期自我修正

**发生了什么？**[RoboDoctor，arXiv:2610.35604 v1，10月26日](https://arxiv.org/abs/2610.35604)组织策略/智能体控制分配、选择性干预、物理动作修正，以及“原因→方法→结果→可复用条件”的持久记录。[官方 THUSI-Lab/RoboDoctor](https://github.com/THUSI-Lab/RoboDoctor) 的 README 已核对，blob 为 14563a24cab968a718d0cff785883da40cd8e994；公开控制器、脚本和测试，仍有第三方许可证/模型依赖。作者在精选 **54项 RoboDojo-Sim** 任务报告五维平均 **57.10**、原生成功率 **49.44%**；细化阶段分数 **49.74→57.10**。README 给出 warmup 有效 **162/162**、refinement 有效 **301/324**，无效/剔除样本不可忽略。

**为什么重要、代表什么能力？**非常接近 AURA 的“诊断—修正—经验复用”闭环，不只是一个新的 VLA。**AURA 是否关心？DEEP DIVE；执行影响 MONITOR/BACKLOG。** **可能如何复现/改进？**原 WP1 比较相同策略、能力库、任务和预算下的门控、干预成本、无效回合、隔离的后续独立测试；作者自己承认尚未单独隔离跨回合经验贡献。完整 RoboDojo/Isaac Sim 5.1、模型和推理依赖并非 M9a 的低成本附加项。开源 ≠ 安装成功 ≠ 经过审计的复现。

### B. RoboAuto：物体/场景/交互知识与主动试验

**发生了什么？**[RoboAuto，arXiv:2610.36533 v1，10月27日](https://arxiv.org/abs/2610.36533)明确整理物体、场景和交互层次的知识；将技能与当前物体关系/几何量对齐，分阶段搜索机器人程序，并用主动小试验区分不确定物理假设，检查预期效果是否发生。见[作者项目](https://roboauto-ai.github.io/)；本次未证明代码/权重已形成可运行完整发布。作者称短程 LIBERO-PRO **89.1%**，长程与实机任务有对应改进，仍属作者条件。

**为什么重要、代表什么能力？**“物体中心状态+可用性（affordance）+主动信息获取（active information acquisition）+效果验证”与 AURA 的研究核心高度重叠。**AURA：DEEP DIVE，MONITOR/BACKLOG。** **可能复现/改进：**比较它使用哪些真值/标定信息、未知与失败如何区分、主动探测增加多少运动/观察成本；今后在严格匹配传感预算的操作任务中对照被动观测，不得把评估器真值泄漏给控制策略。不要把主动探测直接加进 M9a。

### C. PDRVLA：可以训练时学世界预测、在线不生成未来视频

**发生了什么？**[PDRVLA，arXiv:2610.37381 v1，10月27日](https://arxiv.org/abs/2610.37381)用冻结视频世界模型做辅助监督，让轻量物理动态模块提取 token 并预测未来 RGB、深度和光流特征；部署时依赖 token 生成动作，**不需要在线生成完整未来视频**。作者报告 LIBERO **99.3%**、LIBERO-Plus **89.9%**、RoboTwin 2.0 **93.6%**、SimplerEnv **81.5%**，来自不同基准，不能合并作一个普遍保证。

**意义/能力：**直接挑战“可靠操作一定需要一个独立在线有界世界模型”。物理预测可能被**蒸馏到快速策略**。**AURA：概念 DEEP DIVE；仅在具备兼容学习基线后作为下一检查点替代方案，当前不新开实验。** **可能复现：**匹配模型、训练数据与真实时延，对比纯动作、物理 token 监督、在线预测器；检验未知物理干扰下的真实效果，而不是仅看特征误差。本次未确认可用完整检查点。

### D. Rollback：在学习型世界模型内回溯、分支生成训练信号

**发生了什么？**[Rollback，arXiv:2610.36068 v1，10月26日](https://arxiv.org/abs/2610.36068)把世界模型当可回溯的“反事实引擎”：在关键决策点尝试不同动作未来，把结果变成动作级监督，再用实际交互通过 LoRA 更新预测模型。作者在三个实机任务报告绝对提升 **10.67/11.11/11.85 个百分点**。

**意义/能力：**明确的“失败经验→反事实→后续策略改进”，但**不是让现实机器人倒回过去，也不证明在线安全恢复**。**AURA：READ→DEEP DIVE，MONITOR/BACKLOG。** **可能复现：**以后先用物理仿真检查点做受控 oracle，保证物理/控制器/策略缓存/RNG 同步恢复并匹配分支次数，避免立即训练巨型 WAM；之后检验学习型预测器在分布外能否可靠排序。

### E. E0.5：把三维几何变成世界—动作模型的基础表示

**发生了什么？**[E0.5，arXiv:2610.36011 v1，10月26日](https://arxiv.org/abs/2610.36011)直接以 3D 基础模型为 WAM 主干，联合生成未来三维状态和动作。作者在无具身预训练的 RoboTwin2.0 报告 **89.90% clean / 50.09% randomized**，随后使用超过16万条 AgiBotWorld-Beta 轨迹获得实机提升。**意义/能力：**把几何动态作为原生预测对象，不再只靠画面逼真度；同时 clean/randomized 差距提醒泛化风险。

**AURA：READ、长期 WATCH；不为 M9a 更换 3D 骨干。** **可能复现：**未来在匹配对象变化、相机标定偏差、接触状态条件下检查预测几何与真实效果，不把不同评估设置中的数字直接比较。

### F. ActiveAlign 与 VLA-Stem：主动标定和底层快速纠错

**发生了什么？**[ActiveAlign，arXiv:2610.36859 v1，10月27日](https://arxiv.org/abs/2610.36859)用主动手臂动作+可微渲染改善手眼标定，并用触碰修正物体位姿。[VLA-Stem，arXiv:2610.37378 v1，10月27日](https://arxiv.org/abs/2610.37378)在冻结 VLA 下方增加快速运动几何/安全修正。**意义/能力：**前者主动降低感知不确定性，后者在高层动作块之间保护快速控制；但都不自动保证任务效果真正实现。

**AURA：ActiveAlign READ（未来 WP2/09），VLA-Stem READ/WATCH（未来 VLA 基线）。** **可能复现：**M9a 摄像头严格中立通过后，再检查现有相机标定漂移与误差，无须采购触觉硬件；另行比较高频纠偏和任务级验证，不能把无碰撞误算为任务完成。

### G. UniManip 与 RoboDojo：创新空间和指标可比性

**发生了什么？**[UniManip，arXiv:2602.13086，2月13日初投/10月24日修订](https://arxiv.org/abs/2602.13086)已经组合高层调度、物体中心场景图、几何落地、记忆诊断与恢复。不能将修订日期当首发。官方[RoboDojo新闻/榜单](https://robodojo-benchmark.com/)于10月27日增加 GO-3 Nano Preview：仿真 agent 赛道五维 **61.90分 / 56.42% 成功**；10月24日 PyRUA-Lean **55.26 / 50.35%**；10月26日另有实机赛道条目。

**意义/能力：**已有大量系统覆盖“代理+记忆+规划+恢复”架构；不同赛道的策略、工具、外部评审和重试成本不能混作一个总排名。**AURA：UniManip 先前工作 DEEP DIVE；榜单 WATCH。** **可能复现：**优先做相同执行器/相同能力库/匹配预算的消融，并按泛化、精细度、长程、记忆和开放指令分开报告，不把某一赛道第一等同全面最强。

## 三、再次确认的上游研究，以及 AURA 不同解释

**AW-0** [arXiv:2610.30136，10月21日](https://arxiv.org/abs/2610.30136)联合建模技能代码、未来视频与动作，核对[官方仓库](https://github.com/ZhuoyangLiu2005/agentic-wam)，README blob 2a576f04955448afa6c62d879e01dbf0a9060bf6。**默认模型生成代码是条件信息，不等同机器人真的执行了这段代码**。代码与检查点有发布，但完整预训练原始语料等没有打包。**READ，暂不全量复现。**

**P² Progress Probes** [arXiv:2610.31613，10月22日](https://arxiv.org/abs/2610.31613)：冻结策略隐藏状态上的轻量进度检测；**Echo** [arXiv:2610.31569，10月22日](https://arxiv.org/abs/2610.31569)：动作生成同时学习停止/失败状态。都可能替代一部分外部昂贵验证，但**进度预测不等于物理效果验证；准确报警不等于干预值得做**。两者依赖学习型基线，M9a 仍是传感信息边界实验。**有针对性 DEEP DIVE，不立即集成。**

**FastHarness** [arXiv:2610.31427，10月22日](https://arxiv.org/abs/2610.31427)，已核对[官方仓库](https://github.com/FastHarness/fast-harness)，README blob 0f2a847b21517eee010f4b3dd8c8f1da9b0b55cf。公开可执行**纯 CPU 符号演示**；真实 RoboDojo 接入另需策略、仿真和评审服务器。**REPRODUCE 仅作 Embodied-AI 实验负责人可选任务，AURA 优先复用其结论而不是重复搭建**；少调用老师还必须证明没有漏掉关键失败。

WholeBodyMem/HuMeGo、UniWALM/UniFlowWAM、OpenTac、Isaac Lab 3.0，以及 NVIDIA 10月20–21日发布属于**上游先前已捕获内容**。HuMeGo 的论文演示不自动等同公开可完整下载数据。新平台或硬件新闻不构成修改 ManiSkill 冻结环境的理由。

## 四、与 DynaHarness 等系统的严谨对照

| 参照对象 | 与 AURA 重叠 | 需要通过对照查清的缺口 |
| --- | --- | --- |
| **DynaHarness（更早）** | 执行治理、失败归因、能力替换和重规划 | 相同技能库和相同策略、同等成本、非特权观察下能否保持收益？ |
| **RoboDoctor（10月26日）** | 选择性切换、动作修正、持久经验 | 经验的**独立测试迁移收益**，是否区别于增加尝试和筛选？ |
| **RoboAuto（10月27日）** | 物体/场景/效果知识、主动探测、阶段验证 | 主动探测在匹配观察/运动成本后比被动感知强多少？ |
| **UniManip（2月初投/10月修订）** | 分层场景与操作图、几何落地、诊断恢复 | 相机偏差、遮挡、物体状态不确定时的有效性语义是什么？ |
| **PDRVLA（10月27日）** | 具备物理预测的低延迟动作控制 | 预测能否在训练阶段蒸馏到快速策略，避免在线 WAM？ |

**解释差异：**AURA 不能再以“VLA+规划+记忆+验证+恢复”本身或“递归自我改进”作为创新性论据。更有检验价值的是：在**非特权传感、状态变化、匹配成本、真正迁移**下，哪些机制实际有必要、何时简化/集成结构反而更好。先前工作压缩创新声明，并不否定我们已有的严谨实验仪器。

**持续假设更新：**PDRVLA 说明动作相关预测可在**训练期**完成并内化进策略；独立**在线世界模型不是必需模块**，需要用实验证明其额外收益。可修订状态和干预价值依然是待检验机制，不是所有系统都必须逐模块搭建。
