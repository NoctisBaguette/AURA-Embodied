# 探索笔记｜Exploration

这里保存随手发现、来源链接、未完成想法、阅读笔记和AI辅助摘要。**不要求材料已经成熟，不要求先有任务分配，也不要求马上解释对当前原型的作用。** 这不是已确认架构和实验结果的目录。

## 最小记录

一个标题和原始来源链接就可以。AI摘要必须标明AI辅助及核验程度；自己的推测也请与原作者结论分开。下面的模板可删减，不是必填表格。

```markdown
# <标题>

来源：<原始链接>
状态：待阅读 / AI辅助摘要未核验 / 已初读 / 部分核验
记录人及日期：<可选>

## 为什么觉得有意思（可选）
……

## 笔记或摘要（可选）
……

## 问题与下一步（可选）
没有确定下一步也可以。
```

## 文件与提交

建议路径：`docs/exploration/<GitHub用户名>/<日期>-<主题>.md`。文件夹按记录人归档，不代表永久分工，也不是私密空间。中文、英文都可以。

可以先在自己的工作分支持续保存、编辑并分享链接，不必为了每次记录都开PR。准备把内容纳入共享分支时，再通过Pull Request提出修改，具体按仓库实际规则执行。探索笔记的检查重点是来源、状态、路径和公开范围，不要求为了合并而完成整篇论文审查。**合并不等于技术背书，不等于批准训练或实验；等待合并不妨碍继续在工作分支开发。**

不想创建文件时，可在仓库Discussions发布；该功能需先启用。讨论成熟后可整理到研究文档，保留原始记录和链接。只有准备承诺一项具体工作时，才需要把问题转成带负责人和交流时间的Issue。

网页创建笔记和分支的操作步骤见 [TEAM_WORKFLOW.md](../../TEAM_WORKFLOW.md)。

## 公开范围

不要上传密码/令牌、个人报名表、受限数据或未获许可的录像。第三方论文和材料优先保存原链接；AI摘要不能代替对关键原文的核验。
